# v0.1.3 本地审阅：先选数据模式，再开始学习

只更新独立开发副本，不覆盖原目录、已安装 Skill 或线上版本；未向 SkillHub / GitHub 发布。此次仍是补丁版本更新。

## 用户可以看到的变化

第一次进入新的学习会话，先由用户明确选择：

1. 由 Skill 创建知识边界：确认保存位置和范围后，通过必要问题建立有依据的记录。
2. 使用自己的数据库：先确认精确位置和范围，默认只读；笔记存在不等于已经掌握。
3. 不使用个人数据：不读取历史画像或个人库、不创建档案，只围绕本轮目标与回答学习。

没有默认项，未选择先等待；知识节点选择不是数据授权。同一会话不用反复选，切换模式、新会话或范围变化需重新确认。无个人数据不计算 Focus；原圆锥机制在有合格数据和候选的分支保留。

## 验证边界

这些结果证明入口分支及本地规则可运行，不证明教学效果已经提升；尚无新一轮 WorkBuddy 实机或真实学习效果验证。选择模式后仍须依据真实回答确认知识边界，不能只问三选一就声称了解用户。

`confirmation_ref` 是 Agent 提交的消息引用，不是外部签名；会话切换由 Agent 按协议识别，CLI 不维护跨会话注册表。直接 Python API 为合成测试和维护保留，不构成绕过学习入口的权限。既有只读操作可使用旧外置事务锁，但不会更新库或导出画像；无个人数据入口不触库、不进锁。通用数据库通过现有只读工具按授权读取，不承诺任意格式自动接入 Vault 程序。
