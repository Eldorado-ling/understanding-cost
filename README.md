# 理解成本学习导航

understanding-cost · v0.1.4 · ELD

**先弄清你已经会什么，再决定先学什么、怎样讲清楚。**

这是给 AI 助手使用的一套学习指导规则，适合学习新知识、补基础、梳理领域的整体关系，或继续已有学习。

## 它怎样帮你学习

- **核心一安排学习路径**：结合你的目标和当前基础，确定哪些内容先学、哪些需要补充。
- **核心二负责讲解与练习**：先解释陌生词，再用文字、对话和必要的图示讲清当前这一点。
- **两个核心持续配合**：把你的实际回答用于调整讲法和学习顺序，再用新的任务检查是否能独立完成。

核心一交给核心二的，不只是“教什么”，还有“哪些知识可以当作已知、哪些词必须先解释”。例如，顺序没错但解释用了陌生词，就先讲清这个词；如果缺的是必须先会的基础，再回头调整顺序。

开始前由你选择：**创建知识边界、使用已有数据库，或不使用个人数据**。知识边界是对当前目标下“你会什么、哪些还不确定”的判断；已有库默认只读，不使用个人数据时不额外建档。喜欢某种讲法、看完教程或说“懂了”，都不等于已经掌握。

## 圆锥的作用

聚焦圆锥是核心一内部辅助安排先后顺序的办法：几步内容都符合学习条件，前面的路径和成本检查仍分不出先后，而且依据足够时，再结合目标、兴趣和学习准备情况，帮助决定先尝试哪一步。

若用圆锥图表示，点对应知识点，比较的是它们对应的可执行学习步骤。位置较高表示更建议先尝试，**不表示已经掌握，也不保证学得更快**。它不直接决定用文字还是视频教学；普通学习不要求你查看这张内部图。

## 试着这样说

> 用 understanding-cost 教我一个新主题。先让我选择资料使用方式，再确认必要的基础，每次讲清楚一小步。

本版仍是需要通过真实使用来检验的试验版本，目标是减少学习所需的时间与精力，不承诺必然学得更快。
